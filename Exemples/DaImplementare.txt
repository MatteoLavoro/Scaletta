┌─────────────────────────────────────────────────────────────────────────────┐
│ MODIFICA #3: GESTIONE Z-INDEX FISSATO                                       │
└─────────────────────────────────────────────────────────────────────────────┘

ESEMPIO (riga 62):
  // Calcola z-index basato su profondità o valore personalizzato
  const computedZIndex = zIndex ?? 1000 + modalDepth * 10;

IMPLEMENTAZIONE (righe 34-46):
  // Calcola e fissa lo z-index alla prima apertura
  if (fixedZIndexRef.current === null && isOpen) {
    fixedZIndexRef.current = zIndex ?? 1000 + modalDepth * 10;
  }

  // Reset z-index quando il modale si chiude
  useEffect(() => {
    if (!isOpen) {
      fixedZIndexRef.current = null;
    }
  }, [isOpen]);

  const computedZIndex = fixedZIndexRef.current ?? zIndex ?? 1000;

MOTIVAZIONE (BUG CRITICO):
  PROBLEMA: Quando si apre un modale annidato, modalDepth aumenta nel context,
            causando un re-render del modale padre con un nuovo z-index
            più alto, che andava sopra al modale figlio.

  SOLUZIONE: Il fixedZIndexRef cattura il valore corretto di z-index al momento
             dell'apertura del modale e lo mantiene fisso per tutta la durata
             di vita del modale, prevenendo ricalcoli indesiderati.

  ESEMPIO DI FUNZIONAMENTO:
    1. Modal 1 apre → modalDepth=0 → fixedZIndexRef=1000
    2. Modal 2 apre → modalDepth=1 → fixedZIndexRef=1010
    3. Modal 1 NON ricalcola z-index, rimane a 1000
    4. Overlay 2 ottiene z-index 1009, copre correttamente Modal 1

IMPLEMENTAZIONE (righe 84-100):
  // Blocca scroll del body quando il modale è aperto
  useEffect(() => {
    if (isOpen) {
      // Solo se non è un modale annidato (skipHistory false significa che è gestito dal context)
      if (!onClose || skipHistory) {
        document.body.style.overflow = "hidden";
        hasSetOverflowRef.current = true;
      }
      return () => {
        // Ripristina overflow solo se questo modale l'ha impostato
        // e non ci sono modali annidati aperti
        if (hasSetOverflowRef.current && !hasNestedModals()) {
          document.body.style.overflow = "";
          hasSetOverflowRef.current = false;
        }
      };
    }
  }, [isOpen, onClose, skipHistory, hasNestedModals]);

MOTIVAZIONE (BUG CRITICO):
  PROBLEMA: Quando si chiudeva un modale annidato, il modale padre ripristinava
            lo scroll del body, permettendo di scorrere la pagina sottostante
            anche se il modale padre era ancora aperto.

  SOLUZIONE:
    1. Solo i modali principali (non annidati) impostano overflow:hidden
    2. hasSetOverflowRef traccia quale modale ha impostato overflow
    3. Overflow viene ripristinato SOLO se non ci sono modali annidati aperti
    4. hasNestedModals() verifica se esistono callback di chiusura annidati
